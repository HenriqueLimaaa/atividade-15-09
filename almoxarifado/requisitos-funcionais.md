# ENTREGA 01 — Requisitos Funcionais

| ID | Requisito | Descrição | Prioridade |
|---|---|---|---|
| RF01 | Autenticação | Permitir login com usuário e senha e informar falha de autenticação. | Alta |
| RF02 | Logout | Permitir encerrar a sessão e voltar ao login. | Alta |
| RF03 | Exibir usuário | Mostrar o nome do usuário autenticado na interface principal. | Média |
| RF04 | Cadastro de produto | Permitir inserir produto, categoria, unidade, estoque atual e estoque mínimo. | Alta |
| RF05 | Listagem de produtos | Carregar automaticamente os produtos cadastrados em tabela. | Alta |
| RF06 | Busca | Permitir pesquisar produtos e atualizar a listagem conforme o termo informado. | Média |
| RF07 | Edição | Permitir alterar os dados de um produto existente. | Alta |
| RF08 | Exclusão | Permitir excluir produto existente, desde que não possua movimentações associadas. | Média |
| RF09 | Validação | Validar campos obrigatórios e valores numéricos antes de salvar. | Alta |
| RF10 | Gestão de estoque | Listar produtos em ordem alfabética e permitir selecionar entrada ou saída. | Alta |
| RF11 | Data de movimentação | Permitir informar a data da entrada ou saída. | Alta |
| RF12 | Atualização de estoque | Atualizar automaticamente o estoque após cada movimentação. | Alta |
| RF13 | Alerta de estoque mínimo | Gerar alerta quando uma saída deixar o estoque abaixo do mínimo configurado. | Alta |
| RF14 | Histórico | Registrar produto, tipo, quantidade, data e responsável de cada movimentação. | Alta |
