# Sistema de Gestão de Estoque — Almoxarifado

Projeto desenvolvido para a atividade prática de Desenvolvimento de Sistema de Gestão de Estoque.

## Tecnologias
- Node.js 22.x
- Express 5.x
- SQLite 3.x (better-sqlite3)
- HTML, CSS e JavaScript

## Estrutura
- `requisitos-funcionais.md` — Entrega 1
- `DER.png` — Entrega 2
- `almoxarifado_db.sql` — Entrega 3
- `sistema/` — Entregas 4, 5, 6 e 7
- `casos-de-teste.md` — Entrega 8
- `requisitos-infraestrutura.md` — Entrega 9

## Como executar
```bash
cd sistema
npm install
npm start
```
Depois, acesse `http://localhost:3000`.

Usuário inicial:
- Usuário: `admin`
- Senha: `1234`
