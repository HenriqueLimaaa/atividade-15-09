# 4. Sistema Web

O sistema contém:
- tela de login;
- dashboard;
- cadastro de produtos;
- controle de entradas e saídas;
- alertas de estoque mínimo;
- histórico de movimentações;
- interface responsiva.

A versão `docs/` é compatível com GitHub Pages. A versão `sistema/` possui backend Node.js/Express e SQLite.
