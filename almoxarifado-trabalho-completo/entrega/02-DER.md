# 2. Diagrama Entidade-Relacionamento

Entidades:
- **USUARIOS**: identifica quem acessa e opera o sistema.
- **PRODUTOS**: representa os itens armazenados.
- **MOVIMENTACOES**: registra entradas e saídas.

Relacionamentos:
- Um usuário pode realizar várias movimentações (1:N).
- Um produto pode possuir várias movimentações (1:N).
