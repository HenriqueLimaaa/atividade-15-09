# 9. Requisitos de Infraestrutura

## Versão completa (Node.js + SQLite)
- CPU: 2 núcleos ou superior
- RAM: 2 GB ou superior
- Armazenamento: 1 GB livre
- Node.js: versão LTS
- Navegador moderno
- Sistema operacional: Windows, Linux ou macOS
- Rede: necessária para acesso remoto ao servidor

## Versão GitHub Pages
- Apenas navegador moderno
- Internet para carregar o site
- Sem necessidade de Node.js no computador do usuário
- Dados da demonstração ficam no `localStorage` do navegador

## Para produção
- HTTPS
- Backend hospedado em servidor
- Banco de dados gerenciado
- Senhas com hash seguro
- Controle de permissões
- Backup periódico
- Variáveis de ambiente para segredos
