# Publicação no GitHub Pages

1. Coloque o conteúdo de `docs/` na pasta `docs` da raiz do repositório.
2. No GitHub, abra **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/docs`.
5. Salve e aguarde a publicação.

A versão Pages é uma demonstração estática: os dados ficam no navegador de cada pessoa. Para uma base compartilhada entre usuários, hospede também o backend da pasta `sistema/` e conecte o frontend à API.
